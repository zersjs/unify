# Tehdit modeli

**Korunan varlıklar:** klavye ve fare kontrolü (uzaktan kod çalıştırmaya eşdeğer), pano içeriği (parola, kişisel veri), cihaz özel anahtarları.

**Güven sınırları:**

1. Yerel ağ ↔ Unify dinleyicisi (güvenilmeyen ağ trafiği).
2. Eşleştirilmiş cihaz ↔ bu bilgisayarın giriş sistemi (yalnızca açık kontrol devrinden sonra).
3. Unify süreci ↔ işletim sistemi anahtar deposu.
4. Web arayüzü ↔ Rust arka ucu (Tauri komutları).

## Saldırı senaryoları ve önlemler

| Senaryo | Önlem | Kod |
|---|---|---|
| Aynı ağdaki biri porta bağlanıp tuş göndermeye çalışır | TLS 1.3 zorunlu; istemci sertifikası zorunlu; parmak izi sabitlenmiş eşle eşleşmeyen `Hello` reddedilir; kimlik doğrulanmadan gelen her mesaj bağlantıyı kapatır | `session.rs::on_hello`, `on_conn_message`; test `unpaired_certificate_is_rejected_after_hello`, `unauthenticated_input_before_hello_closes_connection` |
| Eşleştirme kodunu tahmin etme | SPAKE2: kod ağda gönderilmez, çevrimdışı deneme imkânsız; her bağlantı tek tahmin; 5 hatada pencere kapanır; kod 120 sn geçerli | `pairing.rs`; test `wrong_pairing_code_is_rejected_without_pairing` |
| Eşleştirme sırasında aradaki adam | Onay MAC'i TLS exporter değerine ve iki sertifika parmak izine bağlı; iki ayrı TLS oturumu kuran saldırgan doğrulamayı geçemez; ek olarak kod üreten bilgisayarda parmak izi gösterilip açık onay istenir | `pairing.rs` testleri `different_channel_binding_fails_confirmation`, `swapped_fingerprints_fail_confirmation` |
| Tekrar oynatma | TLS 1.3 kayıt sıra numaraları; 0-RTT ve oturum biletleri kapalı | `tls.rs` |
| Eşleştirilmiş cihaz istem dışı giriş gönderir | Giriş yalnızca `Enter` kabul edildikten sonra uygulanır; giriş paylaşımı kapalıysa `Enter` reddedilir | `control.rs::on_remote_input`; testler `input_from_peer_is_ignored_unless_control_was_granted`, `peer_with_input_sharing_disabled_refuses_control` |
| Bağlantı koparken tuşun basılı kalması | Kontrol edilen taraf basılı tuş/düğme kümesini tutar ve kopmada, `Release`'te, dönüşte bırakır | `PressedState`; test `connection_loss_releases_keys_held_on_controlled_machine` |
| Parola yöneticisi içeriğinin sızması | `ExcludeClipboardContentFromMonitorProcessing`, `Clipboard Viewer Ignore`, `CanIncludeInClipboardHistory=0`, `org.nspasteboard.ConcealedType/TransientType/AutoGeneratedType` işaretli içerik gönderilmez | `windows/clipboard.rs`, `macos/clipboard.rs`; test `concealed_clipboard_content_is_never_sent` |
| Günlüklerden veri sızması | Pano metni, tuş kodları ve anahtarlar hiçbir düzeyde günlüğe yazılmaz; reddedilen bağlantılar yalnızca IP ve kısa parmak iziyle kaydedilir | `tracing` çağrıları |
| Özel anahtarın diskte okunması | Anahtar Keychain / Credential Manager'da; diskte yalnızca açık sertifika | `keystore.rs`, `identity.rs` |
| Kötü niyetli büyük/bozuk paket | Çerçeve ≤ 64 KiB, pano ≤ 16 MiB, parça ≤ 16 KiB, sıra/uzunluk/özet doğrulama, metin alanlarında uzunluk ve kontrol karakteri sınırı | `frame.rs`, `message.rs`, `clipboard.rs` |
| Bağlantı seli | Eşzamanlı el sıkışma en fazla 8; el sıkışma 5 sn, `Hello` 10 sn zaman aşımı | `session.rs` |
| Web arayüzüne enjekte içerik | Sıkı CSP (`script-src 'self'`), prototip dondurma, yalnızca olay dinleme izni; komutlarda uzunluk sınırları | `tauri.conf.json`, `capabilities/default.json`, `commands.rs` |
| Ele geçirilmiş eş | Eşleştirmeyi kaldır veya cihaz kimliğini yenile: eski sertifika anında reddedilir | `remove_peer`, `reset_identity`; test `removing_peer_disconnects_and_rejects_further_sessions` |

## Kapsam dışı

- Aynı kullanıcı oturumunda çalışan kötü amaçlı yazılım (aynı API'lere zaten erişebilir).
- Kilit ekranı, UAC güvenli masaüstü ve yönetici pencereleri: işletim sistemi giriş göndermeyi engeller; Unify bu sınırları aşmaya çalışmaz.
- mDNS kayıtları kimlik doğrulamasızdır; yalnızca adres ipucu olarak kullanılır, güven kararı TLS sabitlemesiyle verilir.
